GEI-NJ API reference

Version 0.2.0.5. Import the six workflow functions from gei_nj.

Input encoding

Rows are cells or cell groups; columns are SNVs. Depth and ratio inputs must have matching, unique row and column names. Depths are finite, nonnegative integer counts. At positive depth, ratios are finite observed ALT/total values in [0, 1]. At zero depth, ratios can be 0 or NaN; both mean missing. Input NaNs generate a warning, and NaNs at positive depth raise an error. Nonzero ratios at zero depth are invalid. Use original observed ratios rather than discretized or coarsely rounded values.

comb_depth_ratio

comb_depth_ratio(ad_depth, ad_ratio)

Validate and combine two AnnData inputs. Match names and reorder depths to the ratio input. Return a new object with original ratios in X and depths in layers["total_depth"]. The depth layer contains the total sequencing depth for each cell–SNV entry. The original zero-depth ratio encoding (0 or NaN) is preserved in X. State assignment marks zero-depth entries as missing in a separate temporary state layer until zero-filling. Neither input is modified.

filter_snvs

filter_snvs(adata, min_total_depth=5, remove_germline=True,
            min_callable_cells_germline=3, min_pooled_ratio_germline=0.90, min_E_germline=10.,
            exclude_snvs=None, depth_layer="total_depth", copy=True, verbose=True)

Retain SNVs meeting the minimum summed depth across cells. Optionally exclude candidate homozygous ALT germline variants and user-specified loci. Filtering reads raw ratios from X and clears processed state layers and their settings. The three parameters ending in _germline apply only when remove_germline=True.

remove = (n_callable >= min_callable_cells_germline) & (
    (pooled_ratio >= min_pooled_ratio_germline) | (E >= min_E_germline)
)

min_total_depth=5Minimum site-level summed depth to retain a SNV.
remove_germline=TrueApply the candidate germline rule above. Setting False leaves depth and user-list filtering active.
min_callable_cells_germline=3Minimum number of cells with depth > 0 for either germline criterion.
min_pooled_ratio_germline=0.90Threshold on sum(ratio × depth) / sum(depth).
min_E_germline=10.Threshold on the all-ALT e-value. This is evidence, not a probability of germline origin.

The all-ALT event requires positive depth and raw ratio exactly 1. The statistic combines a point alternative at all-ALT with a Beta(4, 1) mixture, using the depth-dependent baseline 1/(depth + 1). It identifies candidates with cross-cell all-ALT evidence; it does not verify biological germline origin or provide general heterozygous germline detection. The later zero-filling depth threshold does not alter n_callable.

assign_state

assign_state(adata, method="binary", state_low=0.01,
             layer_name="state", depth_layer="total_depth", copy=True)

Read original observed ratios from X. For method="binary", assign ratios below state_low to 0 and ratios at or above it to 1. For method="continuous", assign raw ratios as continuous states; state_low is not used. Mark zero-depth entries as missing in the output layer_name, which defaults to state. Leave X unchanged, clear earlier processed state layers and their settings, and record the assigned layer name for zero-filling. Return a copy by default; copy=False updates in place. This function can be rerun to change state representation from the original ratios.

zero_filling

zero_filling(adata, min_callable_depth=1, depth_layer="total_depth",
             callable_layer="callable", output_layer="zero_filled_state",
             copy=True, verbose=True)

Read the state layer created by assign_state() and build the binary callable_layer from depth ≥ min_callable_depth. Fill entries below that threshold with 0 and retain assigned values at all other entries. Store the result in output_layer (default zero_filled_state), remove the temporary assigned state layer, and leave X unchanged. The output layer name is recorded for tree construction. At the default threshold, only zero-depth entries are filled. No neighboring-cell estimate is used. To repeat zero-filling or change its threshold, rerun assign_state() first. Return a copy by default; copy=False updates in place. verbose controls the filling summary.

build_nj

build_nj(adata, do_plot=True, wls_weight_power=2.,
         use_branch_lengths=False, rapidnj_binary="rapidnj", group_key=None,
         show_leaf_labels=False, show_legend=True, group_colors=None,
         figsize=(10, 7), title_prefix="GEI-NJ", savepath=None,
         newick_path=None, print_tree_info=False, return_tree_info=False,
         leafcolor_onside=False, layout="rectangular")

Use the finite matrix in layers["zero_filled_state"] to calculate ordinary summed L1 distances. If zero_filling used a custom output_layer, read that recorded layer instead. The filled layer is required; tree construction does not fall back to X. At least three cells, one retained SNV, and some nonzero between-cell distance are required. wls_weight_power must be finite and nonnegative. Call RapidNJ on real cells, then fit an all-reference profile to the fixed tree using constrained WLS. A reference attachment position within a tree edge and a nonnegative reference pendant length are fitted. The attachment point defines the root. The reference is not included during NJ construction and is not retained as an extra output tip.

Weights are (1 + distance_to_reference) ** -wls_weight_power. Power 0 gives equal weights; the default is 2. Negative NJ branch lengths are projected to zero before fitting, without collapsing their splits.

The returned tree stores tip_colors, a mapping from tip names to their resolved colors, and plot_metadata, containing group_key, group_colors, layout, and use_branch_lengths. Static plots and the coordinate viewer use the same tip colors. Newick output does not preserve these attributes.

Write a standalone interactive HTML linking a rooted tree to cell coordinates. Return the output pathlib.Path. No color parameters are needed: colors and tree display settings come from the object returned by build_nj().
